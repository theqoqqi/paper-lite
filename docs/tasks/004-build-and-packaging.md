# [RFC 004] Сборка и упаковка проекта в ZIP для мобильных устройств

## 1. Резюме решений

* **Проблема:** Для тестирования и редактирования кода игры на мобильном телефоне неудобно вручную отбирать и копировать десятки файлов и ассетов. При этом игра обязана сохранять полную автономность (`no-bundler, no-npm`).
* **Решение:**
  * Реализовать легковесный кроссплатформенный скрипт сборки `build.js` в корне проекта на чистом Node.js (без внешних npm-пакетов, используя стандартные модули `fs`, `path`, `zlib`).
  * Скрипт сканирует проект, отфильтровывает служебные и временные файлы согласно `.gitignore` (`.git`, `.idea`, `.vscode`, `__local`, `dist`), и упаковывает проект в стандартный ZIP-архив `dist/paper-lite.zip`.
  * Исходный код (`src/`) и документация сохраняются 1-в-1 без минификации, объединения или изменений, что позволяет полноценно читать и редактировать код прямо на телефоне (в мобильных редакторах Acode, Spck Editor и др.).
  * Изображения переносятся в архив без сжатия в исходном качестве.
  * Папка `dist/` добавляется в `.gitignore`.

---

## 2. Контракты и структура данных

### Команда запуска

```bash
node build.js
```

### Структура внутри `dist/paper-lite.zip`

Архив в точности повторяет структуру репозитория:

```text
paper-lite.zip
├── src/
│   ├── assets/corridors/*.jpg
│   ├── dungeon-generator.js
│   ├── game-data.js
│   ├── game-engine.js
│   ├── game-ui.js
│   ├── index.html
│   ├── player-model.js
│   └── rng-service.js
├── docs/
│   ├── corridor-art-guide.md
│   ├── improvement-ideas.md
│   ├── tasks.md
│   └── tasks/*.md
└── AGENTS.md
```

### Правила фильтрации при сборке

Игнорируются:

* `.git/`
* `.idea/`
* `.vscode/`
* `__local/`
* `dist/`
* Любые временные файлы сборки и сам скрипт `build.js` (опционально исключается из архива дистрибутива).

---

## 3. Архитектура скрипта `build.js`

1. **Формирование ZIP через `archiver`:**
   * Использование `ZipArchive` из пакета `archiver` с максимальным уровнем сжатия (`level: 9`).
   * Потоковая упаковка директорий `src/`, `docs/` и файла `AGENTS.md`.
2. **Изоляция окружения:**
   * Все сборочные артефакты (`package.json`, `package-lock.json`, `node_modules`, `build.js`) исключены из архива.
   * Распакованный архив полностью автономен и не имеет никаких внешних зависимостей.
3. **Логирование и статистика:**
   * Вывод пути к архиву, итогового размера в мегабайтах и байтах.

---

## 4. Пошаговый план реализации

1. [x] **Шаг 1: Обновление `.gitignore`**
   * Добавить директории `node_modules/` и `dist/` в `.gitignore`.
2. [x] **Шаг 2: Создание скрипта `build.js` и установка `archiver`**
   * Добавить `package.json` со скриптом `"build": "node build.js"`.
   * Установить `archiver` в `devDependencies`.
   * Реализовать `build.js` в корне проекта.
3. [x] **Шаг 3: Тестирование и верификация сборки**
   * Выполнить тестовую сборку через `npm run build`.
   * Проверить валидность архива системными средствами (`tar -tf dist/paper-lite.zip`).
   * Убедиться в корректности содержимого и отсутствии служебных файлов.
4. [x] **Шаг 4: Регистрация в документации**
   * Обновить `docs/tasks.md`.
